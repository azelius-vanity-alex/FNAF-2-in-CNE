# INSTRUCTIONS
This is a Codename Engine mod folder. Please put it in your CNE's mods folder. Then, in the main menu, press Tab and switch to "FNAF 2 in CNE", then press Enter!
Have fun

Also, if you want to restart, press F4 and it will send you back to the warning screen.
If you want to switch mods, go to the FNAF title screen and press TAB.
